#MARIE - PROFILE CARD
========================================================================
DESCRIPTION:
An interactive, high-performance profile card website built with 
vanilla HTML, CSS, and JavaScript. Designed with a dark space theme, 
soft aurora glows, interactive starfield animations, real-time location 
clock, social media links, and custom copy-to-clipboard actions.

------------------------------------------------------------------------
FEATURES:
------------------------------------------------------------------------
- Interactive Background:
  * Dynamic starfield with cross-sparkle effects and meteor showers.
  * Soft animated aurora and nebula glows.
  * Optimized using HTML5 Canvas and CSS 3D transforms (`translateZ(0)`) 
    for smooth rendering at high zoom levels.

- Live Local Time:
  * Automatic time display tuned to Canada/Eastern timezone (EDT/EST) 
    with dynamic daylight saving offset detection.

- Social Links & Quick Actions:
  * Custom styled links for Discord, Roblox, Spotify, and Instagram.
  * One-click "Little Things" buttons to copy Discord ID, profile links, 
    and site URL to the clipboard.
  * Sleek toast notifications for copy feedback.

- Dynamic Responsive Layout:
  * Automatic viewport fitting and responsive scaling across mobile, 
    tablet, and desktop displays.
  * High-contrast glassmorphism visual styling with reduced-motion support.

------------------------------------------------------------------------
TECH STACK:
------------------------------------------------------------------------
- HTML5 / CSS3 (CSS Variables, Flexbox, CSS Grid)
- JavaScript (Vanilla JS, HTML5 Canvas API)
- FontAwesome 6.4.0 (Icons)

------------------------------------------------------------------------
USAGE:
------------------------------------------------------------------------
1. Open `index.html` in any web browser.
2. No build tools, external web servers, or NPM packages required.
